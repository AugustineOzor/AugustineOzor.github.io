The NIST Risk Management Framework (RMF), described in **NIST SP 800-37 Rev. 2**, is a structured way to manage the security and privacy risk of a system across its life. It has seven steps.

1. **Prepare:** set up the organisation and system for risk management: roles, risk strategy, common controls and the system's purpose.
2. **Categorise:** describe the system and decide how much harm a loss of confidentiality, integrity or availability would cause.
3. **Select:** choose a baseline of controls from NIST SP 800-53 and tailor it to the system.
4. **Implement:** put the controls in place and document how each one works.
5. **Assess:** have an independent assessor test whether the controls are implemented correctly and working as intended.
6. **Authorise:** a senior official reviews the remaining risk and decides whether the system may operate.
7. **Monitor:** keep watching controls, changes and threats so the authorisation stays valid.

## Why it works

The RMF ties technical work to accountable decisions. Every control traces back to a categorisation, every assessment produces evidence, and a named official signs off on the residual risk.

Although written for US federal systems, the same logic suits any organisation that wants a repeatable, evidence-based security programme.

**Key takeaway:** Prepare, categorise, select, implement, assess, authorise, monitor, then repeat. The RMF turns security into a lifecycle, not a project.
